## Описание

Консольное приложение, реализующее систему управления гильдией магов.  
Чародеи хранятся в гильдии с уникальными именами, каждый управляет своими книгами заклинаний.

### Сущности предметной области

| Сущность | Описание |
|---|---|
| `Spell` (Заклинание) | Название, описание, стихия, мана, сила, продолжительность, минимальный уровень, временной интервал действия |
| `Book` (Книга) | Хранит коллекцию заклинаний, считает сколько раз из неё колдовали |
| `Sorcerer` (Чародей) | Имеет запас маны, коллекцию книг, текущее время; может колдовать и отдыхать |
| `Guild` (Гильдия) | Контейнер чародеев с уникальными именами; поддерживает сохранение состояния и статистику |

---

## Структура модулей

```
Spell.ixx      — структура Spell, шаблон SpellContainer<T>, перечисление Element

Sorcerer.ixx   — класс Sorcerer (импортирует Spell, Book)
Guild.ixx      — класс Guild (импортирует Spell, Sorcerer)
Tools.ixx      — утилиты ввода, пространство имён filters, UI-помощники
main.cpp       — меню гильдии и чародея, точка входа
```

## Функциональность

### Управление гильдией
- Просмотр списка чародеев
- Добавление нового чародея (имя уникально, при добавлении создаётся стартовая книга)
- Удаление чародея
- Переименование чародея
- Переход в меню управления конкретным чародеем
- Статистика по всей гильдии
- Автосохранение при выходе, автозагрузка при запуске

### Управление чародеем
- Просмотр, добавление, удаление, редактирование книг
- Просмотр, добавление, удаление, редактирование заклинаний
- Фильтрация заклинаний по: названию, мане, стихии, уровню, времени суток
- Применение заклинания (проверяется мана и время суток)
- Отдых (восстановление маны, продвижение времени)
- Статистика применений по книгам и стихиям

## Ключевые технические решения

**`std::set<Sorcerer, ByName>`** — основа хранилища гильдии.
Прозрачный компаратор `ByName` обеспечивает сравнение по имени, передавая его напрямую в методы `set.__()`.

**Модули C++20** — проект использует именованные модули (`.ixx`) вместо заголовочных файлов, что ускоряет компиляцию и устраняет проблему повторного включения.

**`SpellContainer<T>`** — шаблонный класс-контейнер на основе `std::vector` с методами добавления, удаления, изменения, сортировки и фильтрации через `std::function`.

## Сборка и запуск

**Требования:**
- Visual Studio 2022 (или новее)
- Стандарт языка: C++20
- Платформа: Windows (используется `Windows.h` для настройки кодировки консоли)

**Порядок сборки:**
1. Открыть файл решения `.sln` в Visual Studio
2. Убедиться, что в свойствах проекта выбран стандарт **C++20**:  
   `Проект → Свойства → C/C++ → Язык → Стандарт языка C++ → ISO C++20`
3. Собрать: `Сборка → Собрать решение` (Ctrl+Shift+B)
4. Запустить: F5 или Ctrl+F5

**Файл сохранения** создаётся автоматически в папке с исполняемым файлом:  
`guild_save.txt`

## Формат файла заклинания (для ручного создания тестовых данных)

```
Название заклинания
Краткое описание заклинания
<стихия 1-4> <мана> <сила> <мин_уровень> <длительность_мин>
<ЧЧ:ММ начало> <ЧЧ:ММ конец>
```

Пример:
```
Fireball
Огненный шар, наносящий урон всем в радиусе
4 50 120 5 30
20:00 04:00
```

Стихии: `1` — Вода, `2` — Земля, `3` — Воздух, `4` — Огонь
